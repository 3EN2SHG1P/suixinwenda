# 文档索引

本目录存放「随心问答」的完整文档。**只是使用**的话：安装版从
[Releases](https://github.com/3EN2SHG1P/suixinwenda/releases) 下载安装包即可，源码方式再看 [README](../README.md) 第 2 节；
这里解决的是「跑起来之后，想弄明白某件事该看哪份」。

## 3. 阅读顺序建议

- **只想用**：安装版直接下载打开 → 使用手册；源码方式先看 README 第 2 节 → 使用手册
- **想改代码**：README 第 1 节（架构与数据流）→ `docs/踩坑与FAQ.md` 第 6 节（改代码注意事项）→ CONTRIBUTING
- **想改界面**：页面设计规范 → `desktop/src/renderer/styles.css` 的 Token 定义
- **想发布**：打包与发布 第 1 节门禁 → 第 2 节打包 → 发布流程

## 4. 文档口径

- **行为以代码与运行中的接口文档为准**：后端起来后访问 <http://127.0.0.1:8010/docs>（端口取自 `backend/.env` 的 `BACKEND_PORT`）是唯一权威的接口定义，文档里的接口清单是它的文字版快照。
- **配色与结构以源码为准**：`desktop/src/renderer/styles.css` 的 `:root`（浅色）与 `[data-theme='dark']`（深色）是视觉唯一出处；`desktop/src/renderer/index.html` 是结构唯一出处。
- **启动行为以 `start.ps1` 为准**：各阶段输出与 `start.log` 逐行对应，文档里的阶段名与之保持一致。
- **版本变更看 [CHANGELOG](../CHANGELOG.md)**；安全问题看 [SECURITY](../SECURITY.md)；提问与求助看 [SUPPORT](../SUPPORT.md)；行为准则看 [CODE_OF_CONDUCT](../CODE_OF_CONDUCT.md)；第三方组件许可看 [THIRD-PARTY-NOTICES](../THIRD-PARTY-NOTICES.md)；品牌与 logo 使用范围看 [NOTICE](../NOTICE)；英文说明看 [README.en.md](../README.en.md)。
