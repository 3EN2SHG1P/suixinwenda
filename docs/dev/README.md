# 开发者文档

> 文档索引：[docs/README.md](../README.md)

本目录放**改代码、发版本时才需要**的文档。只是使用本项目（装好、聊天、备份、提问）不需要读这里的任何内容。

| 文档 | 写给谁 | 里面是什么 |
|---|---|---|
| [页面设计规范](./页面设计规范.md) | 改界面的人 | 设计原则、页面清单与导航、各页面版块结构、色彩与字号 Token、组件划分与复用、响应式、交互与动效、可访问性、性能基线、落地自查 |
| [设计取舍](./设计取舍.md) | 动渲染 / 上下文 / 上传的人 | 为什么按块增量渲染、历史图片重放的预算怎么定、上传为什么分块暂存 |
| [发布流程](./发布流程.md) | 仓库维护者 | tag 触发的自动发版链路、产物校验、重打 tag 与失败重试的做法 |

新手先看 [CONTRIBUTING](../../CONTRIBUTING.md)；环境跑不起来看 [踩坑与 FAQ](../踩坑与FAQ.md)；
自己出安装包、处理卸载残留看 [打包与发布](../打包与发布.md)。
